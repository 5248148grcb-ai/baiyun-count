# 白云记账

一款开源免费、纯本地、注重隐私的个人记账 App（安卓）。数据完全保存在本机，不上传任何云端。

![App 图标](图标.png)

## 为什么选择白云记账

- **纯本地存储** - 所有数据只保存在手机本地，不联网、不上传、无广告、无会员
- **自动记账** - 支持微信/支付宝支付通知监听、截图识别，付款后自动入账
- **完全离线可用** - 记账、图表、识别全部本地运行，无网也能用
- **简洁美观** - 极简纯色界面，亮色/暗色/跟随系统，多种主题色可选
- **数据自由** - 支持 CSV/JSON 导入导出，兼容主流记账软件格式

## 功能特性

- 记账：支出 / 收入 / 转账，分类随使用频率自动排序，支持自定义分类
- 明细：多账本、日历视图（格内显示收支）、搜索、长按编辑/删除
- 图表：本月/本年/全部支出收入趋势折线图、分类排行
- 资产：账户管理（微信/支付宝等自建）、账户占比环形图、默认收支账户
- 自动化：
  - 通知监听：微信/支付宝支付通知自动识别入账
  - 截图识别：截图后自动识别（支持多笔），区分收支与转账
  - 后台保活引导
- 我的：记账提醒、应用锁（PIN 码）、头像更换、自定义应用名、外观设置
- 数据：全本地存储，导入导出互通
